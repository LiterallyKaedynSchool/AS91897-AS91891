# PinPoint 3D Mapping

## Overview

This work was done for my NCEA Level 2 Digitech in 2026 at Wainuiomata High School.

## The Project (PinPoint 3D Mapping)

This is a website designed for use by Fireproof System Installers who wish to map their worksites before work begins. This map will be saved and can be accessed and moved around in at any time for any user with authorization.

### How to use

1. Open the [index.html](index.html) file\
2. Move around inside, most pages function as required. If they do not need to function, the buttons will be disabled.
